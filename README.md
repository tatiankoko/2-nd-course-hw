# Сайт мини-игр
![screenshot](/sample-img/screenshot.png)
## Описание проекта
Одностраничный сайт мини-игр. Взаимодействие с пользователем осуществляется через alert и prompt.

## Особенности проекта

Адаптивность. Сайт корректно отображается на мобильных, планшетах и десктопах.
Интерактивные элементы. Реализованы анимации при прокрутке, при наведении, анимация полосы прокрутки в шапке сайта и плавные переходы.

## Использованные технологии:
HTML5, CSS3 (Flexbox, Grid);
JavaScript;
Animate.css для анимаций;
Git и GitHub для контроля версий.

## Общее описание всех игр
**Угадай число**<br>
Описание: Пользователь пытается угадать случайное число от одного до ста.

**Простая арифметика**<br>
Описание: Пользователю предлагаются простые арифметические задачи.

**Переверни текст**<br>
Описание: Пользователь вводит текст, который будет перевернут.

**Викторина**<br>
Описание: Викторина с несколькими вопросами и вариантами ответов.

**Камень, ножницы, бумага**<br>
Описание: Игра «Камень, ножницы, бумага» против компьютера.

**Генератор случайных цветов**<br>
Описание: При каждом клике на кнопку фон страницы меняется на случайный цвет.
